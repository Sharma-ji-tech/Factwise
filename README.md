
# Factwise

A web application for managing patients in a virus quarantine and treatment facility.

## Features

- Patient management
- Temperature recording
- Patient detail view
- Facility dashboard and statistics
- Quality analytics

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
